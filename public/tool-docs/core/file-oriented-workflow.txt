【文件导向的 Agent 工作流】

================================================================================
核心理念
================================================================================

"文件系统是 Agent 的外部大脑"

原则：
1. 研究结果 → 写入文件（避免上下文溢出）
2. 任务计划 → 写入文件（防止目标漂移）
3. 错误记录 → 写入文件（支持跨轮次学习）

工作目录：@WorkDir/.agent/（自动创建）

================================================================================
适用场景判断
================================================================================

何时启用文件导向模式：
- 预估步骤 > 5 步
- 涉及大量数据收集/分析
- 需要跨多次对话延续
- 用户明确要求"记录过程"

何时使用轻量模式（仅上下文）：
- 简单任务（≤3 步）
- 一次性查询
- 不涉及复杂状态

================================================================================
第一板斧：研究结果落入文件
================================================================================

目的：避免上下文窗口溢出，支持按需读取

文件路径：@WorkDir/.agent/research/{topic}.md

格式：
```markdown
# 研究：{主题}
创建时间：{timestamp}
更新时间：{timestamp}

## 背景
{用户需求概述}

## 收集的信息
### 来源1：{文件/URL}
{关键摘录，非全文}

### 来源2：{文件/URL}
{关键摘录}

## 关键发现
- {发现1}
- {发现2}

## 待确认
- [ ] {问题1}
- [ ] {问题2}
```

操作规则：
1. 研究开始时创建文件
2. 每获取一批信息，追加到对应章节
3. 上下文中只保留"文件路径 + 关键发现摘要"
4. 需要详细信息时，read_file 按需加载

示例调用：
```
# 创建研究文件
filesystem__write_file({
  path: "@WorkDir/.agent/research/market-analysis.md",
  content: "# 研究：市场分析\n创建时间：2024-01-15\n\n## 背景\n用户需要..."
})

# 追加信息
filesystem__append_file({
  path: "@WorkDir/.agent/research/market-analysis.md",
  content: "\n### 来源：财报.pdf\n- 营收增长 15%\n- 利润率下降 2%"
})
```

================================================================================
第二板斧：任务计划落入文件
================================================================================

目的：防止目标漂移，支持断点续做

文件路径：@WorkDir/.agent/todo.md

格式：
```markdown
# 任务：{一句话描述}
创建时间：{timestamp}
状态：进行中 | 已完成 | 已暂停

## 目标
{用户的核心目标，原话引用}

## 约束条件
- {约束1}
- {约束2}

## 执行计划
1. [x] {已完成步骤} ✓ {完成时间}
2. [x] {已完成步骤} ✓ {完成时间}
3. [ ] {当前步骤} ← 当前
4. [ ] {待执行步骤}
5. [ ] {待执行步骤}

## 风险与备选
- 风险：{描述} → 备选：{方案}

## 执行日志
### {timestamp}
- 执行：{操作}
- 结果：{结果}

### {timestamp}
- 执行：{操作}
- 结果：{结果}
```

操作规则：
1. 复杂任务开始时创建 todo.md
2. 每完成一步，更新状态 [ ] → [x]
3. 每次行动前，先读取 todo.md 确认当前步骤
4. 遇到变更，更新计划并记录原因

示例调用：
```
# 创建计划
filesystem__write_file({
  path: "@WorkDir/.agent/todo.md",
  content: "# 任务：批量转换文档格式\n状态：进行中\n\n## 执行计划\n1. [ ] 扫描目录..."
})

# 更新进度
filesystem__write_file({
  path: "@WorkDir/.agent/todo.md",
  content: "{更新后的完整内容}"
})
```

断点续做：
- 用户中断后返回，agent 应先检查 @WorkDir/.agent/todo.md
- 如存在未完成任务，询问用户是否继续

================================================================================
第三板斧：错误记录落入文件
================================================================================

目的：跨轮次学习，避免重复踩坑

文件路径：@WorkDir/.agent/errors.log

格式：
```
[{timestamp}] {error_type}
操作：{what_was_attempted}
错误：{error_message}
原因：{analysis}
解决：{how_it_was_resolved | "待解决"}
---
```

操作规则：
1. 遇到非平凡错误，追加到 errors.log
2. 执行类似操作前，检查 errors.log 避免重复
3. 定期清理（保留最近 50 条）

示例调用：
```
# 追加错误
filesystem__append_file({
  path: "@WorkDir/.agent/errors.log",
  content: "[2024-01-15 10:30] COMMAND_FAILED\n操作：pandoc convert\n错误：Font not found\n原因：系统缺少中文字体\n解决：使用 --pdf-engine=wkhtmltopdf\n---\n"
})
```

================================================================================
与 Skills 的结合
================================================================================

Skills 可以定义特定任务的文件模板，自动引导 agent 使用文件导向工作流。

Skill 文件模板示例（在 SKILL.md 中）：
```markdown
## 工作流模板

执行此 Skill 时，自动创建以下文件结构：

@WorkDir/.agent/
├── todo.md          # 使用下方模板
├── research/        # 研究结果目录
└── output/          # 最终输出目录

### todo.md 模板
{预定义的任务步骤模板}
```

Agent 加载 Skill 后的行为：
1. 读取 Skill 的工作流模板
2. 在 @WorkDir/.agent/ 创建对应结构
3. 按模板初始化 todo.md
4. 执行过程中持续更新文件

================================================================================
会话恢复协议
================================================================================

当用户开始新对话时，agent 应：

1. 检查是否存在未完成任务：
   ```
   filesystem__list_directory({ path: "@WorkDir/.agent/" })
   ```

2. 如果存在 todo.md 且状态为"进行中"：
   ```
   filesystem__read_file({ path: "@WorkDir/.agent/todo.md" })
   ```
   
3. 询问用户：
   "检测到未完成的任务：{任务名称}
   已完成 {n}/{total} 步，当前在：{当前步骤}
   是否继续？"

4. 用户确认后，从断点继续执行

================================================================================
文件清理策略
================================================================================

自动清理规则：
- 任务完成后，询问用户是否保留工作文件
- 默认保留 7 天后自动清理
- errors.log 保留最近 50 条

手动清理命令（用户可触发）：
- "清理 agent 工作目录" → 删除 @WorkDir/.agent/

================================================================================
轻量模式 vs 完整模式
================================================================================

| 特征 | 轻量模式 | 完整模式（文件导向）|
|------|---------|-------------------|
| 适用场景 | ≤3 步简单任务 | >5 步复杂任务 |
| 研究结果 | 保留在上下文 | 写入 research/*.md |
| 任务计划 | 口头描述 | 写入 todo.md |
| 错误记录 | 当场处理 | 追加 errors.log |
| 断点续做 | 不支持 | 支持 |
| Token 消耗 | 较高（全在上下文）| 较低（按需加载）|

模式选择提示词：
```
任务评估：
- 步骤数 > 5 或 涉及大量数据 → 启用文件导向模式
- 用户说"记录过程" / "可能要分多次完成" → 启用文件导向模式
- 否则 → 使用轻量模式
```
