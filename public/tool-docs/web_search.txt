Web Search Tools (web_search__*) — 网络工具使用指南

## 可用工具

### web_search__search
在互联网搜索信息。

参数：
- query: 搜索关键词

### web_search__fetch
抓取网页内容，返回标题、正文和链接。

参数：
- url: 网页地址

### web_search__download
下载文件到本地（图片、文档、视频等）。

参数：
- url: 文件下载地址（必须是直链，不是页面链接）
- savePath: 保存路径（相对于 @WorkDir 或绝对路径）
- filename: 可选，自定义文件名

## 免费图片下载（重要！）

### Unsplash 图片下载
❌ 错误：`https://unsplash.com/photos/xxx` （页面链接，需登录）
❌ 错误：`https://unsplash.com/photos/xxx/download` （404）
✅ 正确：`https://images.unsplash.com/photo-{id}?w=800`

下载流程：
1. 搜索：`query = "猫 site:unsplash.com"`
2. 从结果中提取图片 ID（如 `photo-1514888286974-6c03e2ca1dba`）
3. 构造直链：`https://images.unsplash.com/photo-1514888286974-6c03e2ca1dba?w=800`
4. 下载：`web_search__download({ url: "直链", savePath: "images/cat.jpg" })`

### Pexels 图片下载
✅ 直链格式：`https://images.pexels.com/photos/{id}/{filename}.jpeg?auto=compress&cs=tinysrgb&w=800`

下载流程：
1. 搜索：`query = "猫 site:pexels.com"`
2. 从结果中提取图片路径
3. 构造直链（添加 ?w=800 参数控制大小）
4. 下载

### Pixabay 图片下载
✅ 直链格式：`https://pixabay.com/get/{filename}`（需从页面提取）

## 免费资源 API（无需搜索直接调用）

### 天气查询 - wttr.in
无需 API Key，直接 fetch 即可。

用法：
```
# 获取天气（纯文本）
web_search__fetch({ url: "https://wttr.in/Beijing?format=3" })
→ "Beijing: ☀️ +5°C"

# 详细天气（格式化）
web_search__fetch({ url: "https://wttr.in/Shanghai?format=%l:+%c+%t+%w" })
→ "Shanghai: ☁️ +8°C ↑12km/h"

# 获取天气图片
web_search__download({ url: "https://wttr.in/Tokyo.png", savePath: "weather.png" })
```

格式化参数：
- %l 位置名
- %c 天气图标
- %C 天气描述
- %t 温度
- %w 风速
- %h 湿度
- %m 月相

更多：https://github.com/chubin/wttr.in

## 常见任务示例

### 搜索并下载猫图片（正确方式）
```
1. web_search__search({ query: "cat images site:pexels.com" })

2. 从结果中找到 Pexels 图片页面 URL，提取图片 ID

3. 构造直链：
   https://images.pexels.com/photos/45201/kitty-cat-kitten-pet-45201.jpeg?w=800

4. web_search__download({ 
     url: "https://images.pexels.com/photos/45201/kitty-cat-kitten-pet-45201.jpeg?w=800", 
     savePath: "images/cat1.jpg" 
   })

5. filesystem__list_directory({ path: "@WorkDir/images" })
   → 验证下载结果
```

### 查询天气并告诉用户
```
1. web_search__fetch({ url: "https://wttr.in/用户城市?format=%l:+%C+%t+湿度%h" })

2. 直接用结果回答用户
```

## 错误处理

1. **下载 404**
   - 检查 URL 是否是直链（不是页面链接）
   - 尝试备选图片源（Pexels/Pixabay）

2. **图片需要登录**
   - 使用 `images.unsplash.com` 或 `images.pexels.com` 直链
   - 不要使用 `/download` 路径

3. **搜索无结果**
   - 简化关键词
   - 尝试其他图片源
