Web Search Tools (web_search__*) — how to use them

## Tools

### web_search__search
Searches the internet.

### web_search__fetch
Fetches a page and returns its title, body text and links.

### web_search__download
Downloads a file to disk. Parameters: url (a DIRECT link), savePath, filename (optional)

---

## ⚠️ Downloading images: use the Pexels API (most reliable)

**Do not use general search to download images.** The URLs in search results are
usually not directly downloadable.

### Pexels API (recommended, no API key)

Fetch the Pexels search page; the HTML contains direct image links:

```
1. Fetch the Pexels search page:
   web_search__fetch({ url: "https://www.pexels.com/search/cat/" })
   → extract images.pexels.com links from the returned HTML

2. Download the direct link:
   web_search__download({
     url: "https://images.pexels.com/photos/45201/kitty-cat-kitten-pet-45201.jpeg?auto=compress&cs=tinysrgb&w=800",
     savePath: "images/cat.jpg"
   })
```

### Direct link formats known to work

| Source | Direct link format | Example |
|--------|--------------------|---------|
| Pexels | `https://images.pexels.com/photos/{id}/{name}.jpeg?w=800` | `https://images.pexels.com/photos/45201/kitty-cat-kitten-pet-45201.jpeg?w=800` |
| Unsplash | `https://images.unsplash.com/photo-{id}?w=800` | `https://images.unsplash.com/photo-1514888286974-6c03e2ca1dba?w=800` |

### ❌ Common mistakes

- `https://unsplash.com/photos/xxx` → a page, and it needs a login
- `https://unsplash.com/photos/xxx/download` → 404
- image URLs taken straight out of general search results → usually not downloadable

### ✅ The correct flow (download a cat photo)

```
Step 1: fetch the Pexels page
web_search__fetch({ url: "https://www.pexels.com/search/cat/" })

Step 2: extract an images.pexels.com link from the response
(look for URLs shaped like https://images.pexels.com/photos/xxxxx/xxxxx.jpeg)

Step 3: download it
web_search__download({
  url: "https://images.pexels.com/photos/45201/kitty-cat-kitten-pet-45201.jpeg?w=800",
  savePath: "images/cat1.jpg"
})

Step 4: verify
filesystem__list_directory({ path: "@WorkDir/images" })
```

## Free resource APIs (call them directly, no search)

### Weather - wttr.in
No API key; fetch it directly.

```
# Plain text weather
web_search__fetch({ url: "https://wttr.in/Beijing?format=3" })
→ "Beijing: ☀️ +5°C"

# Detailed weather (formatted)
web_search__fetch({ url: "https://wttr.in/Shanghai?format=%l:+%c+%t+%w" })
→ "Shanghai: ☁️ +8°C ↑12km/h"

# Weather as an image
web_search__download({ url: "https://wttr.in/Tokyo.png", savePath: "weather.png" })
```

Format specifiers:
- %l location
- %c weather icon
- %C weather description
- %t temperature
- %w wind
- %h humidity
- %m moon phase

More: https://github.com/chubin/wttr.in

## Worked examples

### Search for and download a cat photo (the right way)
```
1. web_search__search({ query: "cat images site:pexels.com" })

2. Pick a Pexels photo URL from the results and take the photo id from it

3. Build the direct link:
   https://images.pexels.com/photos/45201/kitty-cat-kitten-pet-45201.jpeg?w=800

4. web_search__download({ 
     url: "https://images.pexels.com/photos/45201/kitty-cat-kitten-pet-45201.jpeg?w=800", 
     savePath: "images/cat1.jpg" 
   })

5. filesystem__list_directory({ path: "@WorkDir/images" })
   → verify the download
```

### Weather for the user's city
```
1. web_search__fetch({ url: "https://wttr.in/{user's city}?format=%l:+%C+%t+humidity%h" })

2. Answer the user from the response
```

## Error handling

1. **Download returns 404**
   - check that the URL is a direct link (not a page link)
   - try another source (Pexels/Pixabay)

2. **Image requires a login**
   - use the `images.unsplash.com` or `images.pexels.com` direct links
   - never use a `/download` path

3. **Search returns nothing**
   - simplify the keywords
   - try another image source
