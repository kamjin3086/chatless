fs__* — 文件系统工具

## 工具列表

| 工具 | 用途 |
|------|------|
| fs__read | 读取文件内容 |
| fs__write | 写入文件（覆盖） |
| fs__ls | 列出目录内容 |
| fs__mkdir | 创建目录（递归） |
| fs__rm | 删除文件 |
| fs__mv | 重命名/移动文件 |

## 路径格式

- 支持别名：`@WorkDir/...`（自动解析）
- Windows：`C:/Users/...`（推荐正斜杠）
- Unix：`/home/user/...`

## 使用示例

```
fs__read({ path: "@WorkDir/config.json" })
fs__write({ path: "@WorkDir/output.txt", content: "Hello" })
fs__ls({ path: "@WorkDir" })
fs__mkdir({ path: "@WorkDir/images" })
fs__rm({ path: "@WorkDir/temp.txt" })
fs__mv({ oldPath: "@WorkDir/a.txt", newPath: "@WorkDir/b.txt" })
```

## 操作前检查

- 不确定路径？→ 先 fs__ls 确认
- 覆盖文件？→ 先 fs__read 或提示用户
- 新建文件？→ 确认父目录存在

## 授权机制

- 直接调用，无需先探测权限
- 越界访问会弹出授权卡片

## 错误处理

- AUTH_DENIED → 提示用户授权
- PATH_NOT_FOUND → 检查路径拼写

## 与 shell__run 的选择

| 场景 | 推荐 |
|------|------|
| 简单文件操作 | fs__*（优先） |
| 调用外部程序 | shell__run |
| 批量/复杂转换 | shell__run 脚本模式 |
