fs__* — filesystem tools

## Tools

| Tool | Purpose |
|------|---------|
| fs__read | read a file |
| fs__write | write a file (overwrites) |
| fs__ls | list a directory |
| fs__mkdir | create a directory (recursive) |
| fs__rm | delete a file |
| fs__mv | rename / move a file |

## Path formats

- Alias: `@WorkDir/...` (resolved automatically)
- Windows: `C:/Users/...` (forward slashes preferred)
- Unix: `/home/user/...`

## Examples

```
fs__read({ path: "@WorkDir/config.json" })
fs__write({ path: "@WorkDir/output.txt", content: "Hello" })
fs__ls({ path: "@WorkDir" })
fs__mkdir({ path: "@WorkDir/images" })
fs__rm({ path: "@WorkDir/temp.txt" })
fs__mv({ oldPath: "@WorkDir/a.txt", newPath: "@WorkDir/b.txt" })
```

## Before you act

- Unsure about the path? List it with fs__ls first.
- Overwriting a file? Read it first, or tell the user.
- Creating a file? Make sure the parent directory exists.

## Authorization

- Call the tool directly; do not probe permissions first.
- Access outside the allowed scope raises an authorization card for the user.

## Errors

- AUTH_DENIED → ask the user to authorize
- PATH_NOT_FOUND → check the spelling of the path

## fs__* or shell__run?

| Task | Use |
|------|-----|
| Simple file work | fs__* (preferred) |
| Running an external program | shell__run |
| Batch or complex transformation | shell__run with a script |
