Shell Executor (shell_executor__execute_command) — 工具使用指南

## 用途
在沙盒环境中运行外部命令（python/node/git/npm 等）。
仅在 filesystem 无法直接完成任务时使用。

## 工作目录（重要）
- 优先显式传递 workingDir
- 默认使用 `@WorkDir`（AppData 工作区）
- 项目相关命令（npm/git）→ 设置为项目目录

## 命令格式（关键）
- 按正常命令行格式编写，不要额外转义
- 正确：`python -c "import docx; print('ok')"`
- 错误：`python -c \"import docx\"`

## 方法优先级
1. filesystem → 简单文件操作
2. shell_executor → 调用现成工具
3. 脚本 + shell_executor → 复杂逻辑

## 错误处理（快速参考）
- AUTH_DENIED → 请用户授权后再试
- 命令失败 → 分析 stderr，调整参数
- 同一错误最多重试 2 次
- 2 次失败 → 切换方法或告知用户

## 注意事项
- 写脚本 ≠ 完成任务，必须执行并验证
- 长时间命令考虑超时参数
