Follow-up Prompt (First Round) — After Tool Call

## When Tool Succeeded

工具调用已完成。请基于结果回答用户问题。

【决策流程】
1. 阅读工具返回的结果
2. 结果足够 → 直接给出最终答案（简洁明了）
3. 结果不足 → 继续调用工具补充（见下方规则）

【继续调用规则】
- 只为"缺失/不确定"的信息调用，避免无意义探索
- 可并行调用多个工具（≤3 个），参数必须具体且不重复
- 重试同一工具时：必须改变参数（不要原样重复）
- 预算：最多再补充 2 轮；超过后必须基于已有信息回答

【输出要求】
- 最终答案：简洁中文，直接回答用户问题
- 如有信息缺口：说明缺什么，给出最佳可能答案

## When Tool Failed (hasError=true)

工具调用遇到错误。请基于错误信息处理。

【错误处理策略】
1. AUTH_DENIED（权限拒绝）→ 停止重试，提示用户授权
2. PATH_NOT_FOUND（路径不存在）→ 检查路径，或用 list_directory 确认
3. COMMAND_FAILED（命令失败）→ 分析 stderr，调整参数
4. 连接错误 → 直接重试（系统会自动重连）
5. 无法解决 → 基于已有知识回答，并说明遇到的问题

【重试规则】
- 同一错误最多重试 2 次，每次必须改变参数
- 2 次失败后：切换备选方案（filesystem ↔ shell_executor）
- 确实无法解决：告知用户问题和建议
