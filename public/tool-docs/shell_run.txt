shell__run — run a command

## Scope
Runs external programs and system commands.
**For file work, prefer the fs tools.**

## Choosing a tool

| Task | Use |
|------|-----|
| Read/write/delete files, create directories | fs__* (preferred) |
| Download a file | web__download |
| Run a program or command | shell__run |

## Use the platform's native commands

**Match the commands to the current platform.**

### Windows → PowerShell

```powershell
# Write PowerShell directly (do not wrap it in `powershell -Command` again)
New-Item -ItemType Directory -Path 'images' -Force
Remove-Item -Path 'temp' -Recurse -Force
Copy-Item -Path 'a.txt' -Destination 'b.txt'
Invoke-WebRequest -Uri 'URL' -OutFile 'file.zip'

# Run programs directly
python script.py
node app.js
git status
npm install
```

### macOS / Linux → Unix

```bash
mkdir -p images
rm -rf temp
cp a.txt b.txt
curl -L -o file.zip "URL"

# Run programs
python3 script.py
node app.js
git status
npm install
```

## Common mistakes

| Mistake | Fix |
|---------|-----|
| `mkdir -p` on Windows | use PowerShell `New-Item` |
| `rm -rf` on Windows | use PowerShell `Remove-Item` |
| `curl` on Windows | use `Invoke-WebRequest` |

## Script mode (complex logic)

Pass a code block and it is executed for you:

```python
import os
for i, f in enumerate(os.listdir("photos")):
    os.rename(f"photos/{f}", f"photos/img_{i:03d}.jpg")
```

## Parameters

- command: the command to run. **Accepts the @WorkDir alias** (for example `node @WorkDir/script.js`)
- workingDir: working directory (optional). Accepts @WorkDir, another alias, or an absolute path.
- timeout: milliseconds before the command is killed (default 30000)

## The @WorkDir alias

`@WorkDir` inside a command is replaced with the absolute path of the user's working directory:

```
# Examples
node @WorkDir/script.js
cd @WorkDir && npm install
python @WorkDir/tools/convert.py
```

## Choosing `shell` (important)

- Windows: auto / cmd / powershell (pwsh counts as powershell)
- macOS/Linux: auto / bash

Notes:
- `shell` is the command interpreter, not a runtime (never pass node/python here).
- Commands that use shell syntax such as `cd ... && ...` need auto, or an explicit cmd/powershell/bash.
