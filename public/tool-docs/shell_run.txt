shell__run — 运行命令

## 定位
运行外部程序和系统命令。
**文件操作首选 fs 工具！**

## 工具选择

| 任务 | 推荐工具 |
|------|----------|
| 读/写/删文件、创建目录 | fs__*（首选） |
| 下载文件 | web__download |
| 运行程序/命令 | shell__run |

## 平台原生命令

**根据当前平台使用对应的原生命令！**

### Windows → PowerShell

```powershell
# 直接写 PowerShell 命令即可（不要再手动包一层 powershell -Command）
New-Item -ItemType Directory -Path 'images' -Force
Remove-Item -Path 'temp' -Recurse -Force
Copy-Item -Path 'a.txt' -Destination 'b.txt'
Invoke-WebRequest -Uri 'URL' -OutFile 'file.zip'

# 直接运行程序
python script.py
node app.js
git status
npm install
```

### macOS / Linux → Unix

```bash
mkdir -p images
rm -rf temp
cp a.txt b.txt
curl -L -o file.zip "URL"

# 运行程序
python3 script.py
node app.js
git status
npm install
```

## 常见错误

| 错误 | 修正 |
|------|------|
| Windows 用 mkdir -p | 用 PowerShell New-Item |
| Windows 用 rm -rf | 用 PowerShell Remove-Item |
| Windows 用 curl | 用 Invoke-WebRequest |

## 脚本模式（复杂逻辑）

传入代码块，系统自动执行：

```python
import os
for i, f in enumerate(os.listdir("photos")):
    os.rename(f"photos/{f}", f"photos/img_{i:03d}.jpg")
```

## 参数

- command：要执行的命令。**支持 @WorkDir 别名**（如 `node @WorkDir/script.js`）
- workingDir：工作目录（可选）。支持 @WorkDir、@别名、绝对路径
- timeout：超时毫秒（默认 30000）

## @WorkDir 别名用法

命令中的 `@WorkDir` 会自动替换为用户工作目录的绝对路径：

```
# 示例
node @WorkDir/script.js
cd @WorkDir && npm install
python @WorkDir/tools/convert.py
```

## shell 选择（重要）

- Windows：auto / cmd / powershell（pwsh 视为 powershell）
- macOS/Linux：auto / bash

提示：
- shell 是“命令解释器类型”，不是运行时（不要填 node/python）。
- `cd ... && ...` 这种包含 shell 语法的命令，请用 auto 或显式 cmd/powershell/bash。
