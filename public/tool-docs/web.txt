web__* — 网络工具

## 工具列表

| 工具 | 用途 |
|------|------|
| web__search | 搜索互联网 |
| web__fetch | 抓取网页内容 |
| web__download | 下载文件到本地 |

## 快速示例

```
web__search({ query: "Python 教程" })
web__fetch({ url: "https://wttr.in/Beijing?format=3" })
web__download({ url: "直链URL", savePath: "file.jpg" })
```

---

## 免费 API（无需搜索，直接 fetch）

### 天气

```
web__fetch({ url: "https://wttr.in/Beijing?format=3" })
→ "Beijing: ☀️ +5°C"

web__fetch({ url: "https://wttr.in/Shanghai?format=%l:+%c+%t+%w" })
→ "Shanghai: ☁️ +8°C ↑12km/h"

# 天气图片
web__download({ url: "https://wttr.in/Beijing.png", savePath: "weather.png" })
```

### 汇率

```
web__fetch({ url: "https://api.exchangerate-api.com/v4/latest/USD" })
```

### IP 信息

```
web__fetch({ url: "https://ipinfo.io/json" })
```

---

## 错误处理

| 情况 | 处理方式 |
|------|----------|
| 搜索返回 [] | 换关键词或换方法 |
| fetch 返回 "Just a moment..." | 被网站拦截，换其他网站或方法 |
| 下载失败 | 确认 URL 是可直接下载的直链 |
