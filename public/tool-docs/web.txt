web__* — web tools

## Tools

| Tool | Purpose |
|------|---------|
| web__search | search the internet |
| web__fetch | fetch the contents of a page |
| web__download | download a file to disk |

## Quick examples

```
web__search({ query: "python tutorial" })
web__fetch({ url: "https://wttr.in/Beijing?format=3" })
web__download({ url: "DIRECT_URL", savePath: "file.jpg" })
```

---

## Free APIs (fetch directly, no search needed)

### Weather

```
web__fetch({ url: "https://wttr.in/Beijing?format=3" })
→ "Beijing: ☀️ +5°C"

web__fetch({ url: "https://wttr.in/Shanghai?format=%l:+%c+%t+%w" })
→ "Shanghai: ☁️ +8°C ↑12km/h"

# Weather as an image
web__download({ url: "https://wttr.in/Beijing.png", savePath: "weather.png" })
```

### Exchange rates

```
web__fetch({ url: "https://api.exchangerate-api.com/v4/latest/USD" })
```

### IP information

```
web__fetch({ url: "https://ipinfo.io/json" })
```

## Error handling

| Situation | What to do |
|-----------|------------|
| Search returns [] | change the keywords or the approach |
| fetch returns "Just a moment..." | the site blocked the request; try another site or method |
| Download fails | check that the URL is a direct link to the file |
