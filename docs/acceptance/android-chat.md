# Android chat acceptance (#214 / #212)

Run on a physical ARM64 Android phone with an Android System WebView and a real keyboard enabled. Record the APK build SHA, Android and WebView versions, keyboard, navigation mode, and pass/fail for each item. These are device checks, not covered by the host Back-routing tests.

- **Upgrade without data loss:** Install the candidate over the verified baseline using the same package ID and test signing key. Do not uninstall or clear data first. Open a saved conversation and verify its messages and provider settings are still readable. Relaunch after a new message and verify it remains saved.
- **Clean setup:** Separately use a clean install or disposable profile. From the conversation list, create a chat without granting or choosing a workspace. Use the starter's add-provider action, enter an endpoint and a key if needed, test the connection, enable a model, go Back and select that model in chat. Send a message. Repeat setup with the keyboard open on a short screen and check that the endpoint, key and confirmation remain reachable by scrolling.
- **Navigation and drafts:** Search by a known conversation title, open it, enter an unsent draft, return to the list, open another conversation, then reopen the first. Confirm the draft is still there. Open model settings from both the list and the picker and verify Back returns to the originating surface. Check that desktop window controls, workspace picker and resize handles are absent.
- **Picker and Back:** Open and close the picker several times; active, recent and available models should be readable without bringing up the keyboard. Tap search, compose and commit text with the real IME, and make sure results update without closing the panel. Use system Back: first hides the keyboard with the panel still open, second closes the panel with chat still visible, third returns to the conversation list. Repeat using the three-button Back control and the Back gesture when available. Select a result and confirm the active and recent model update.
- **Keyboard and live chat:** In a chat with a long history, enter a multiline message; the keyboard must not cover the composer or send/stop buttons. Use the send button, scroll a long streamed reply with touch, stop generation and retry/resume. Switch to the list and reopen the chat during a stream; verify the turn continues to update and is durable after relaunch.
- **Layout:** Repeat list, chat and picker checks in light/dark mode and at larger text sizes. Rotate the phone with search or the composer active; verify no important controls are obscured by the keyboard, status/navigation bars or a display cutout.

Photo, document, countdown and directory behavior are separate slices and are not accepted by this checklist.
