## 已验收的实现

### Agent 执行

- 模型请求按真实端点调度，每个请求有独立 ID、取消句柄和终态；普通回答、摘要和标题共用调度器。
- 完整模型回复和工具请求先通过 Rust/SQLx 单事务保存，再执行工具。工具开始、结果、审批和运行状态均有持久化边界。
- 首次输入和运行中补充共用 `RunInput`，支持正文、图片和附件文档 ID。补充先保存为排队状态，在完整工具结果组之后交付。
- 继续创建关联新运行；已开始但无结果的调用标记为结果未知。重新生成在执行层禁止工具调用，避免重复副作用。
- 单次审批不修改长期权限；执行前与审批后重新检查文件、MCP、知识挂载和仅规划限制。
- Windows Shell 使用 Job Object，Unix 使用进程组；输出持续排空，取消结果显式返回。
- 摘要检查点按事件范围持久化并复用；大工具结果写入运行所属附件，读取时验证会话和运行血缘。

### 文档与知识库

- 一份文档只持久化一套 `document_chunks`；块包含文档、批次、稳定顺序、原文、搜索文本和真实位置。
- Rust 在单个事务中校验任务、文档版本和当前挂载，发布暂存批次并切换活动批次；失败保留旧批次。
- 知识库和会话附件只保存文档关系。附件文件写入应用管理目录，SQLite 保存关系，全文不再写入 localStorage。
- TXT、Markdown、PDF 和 DOCX 使用统一解析、分块、FTS、搜索及读取入口；PDF 保留按页提取结果。
- `knowledge_list/search/read` 每次执行都按当前会话挂载重新计算范围。模型给出的 ID 只能缩小范围。
- 顺序游标绑定 `{documentId,batchId,chunkIndex,offset}`；重建后旧游标明确失效。重复段落不会按正文去重。
- 引用只登记实际交付给模型的文本，并保存文档哈希、块、位置和文本快照；继续运行恢复旧映射后分配新编号。
- 词法批次先发布，embedding 进入持久化后台队列；任务支持取消、失败重试和重启恢复。取消后的迟到错误不能覆盖取消状态。
- Dense 搜索在 Rust 中扫描当前授权文档的活动批次，只向 WebView 返回 Top-K；词法与 Dense 使用 RRF 合并，Dense 故障明确降级。

## 关键回归覆盖

- 同端点排队与等待者取消不会造成并发穿透。
- SSE/NDJSON 无结束标记、未完成原生工具参数和取消会进入明确终态，半截回复不会执行工具。
- 多工具运行的补充输入不会插入同一组工具结果之间；未派发调用保存为未执行。
- MCP 禁用后即使保留旧连接也不能执行；未知副作用不会因传输错误自动重放。
- 原子模型步骤任一事件失败时全部回滚；失败重建保留旧文档批次；撤销挂载后过期任务不能发布。
- 引用只接受本次登记的证据 ID；顺序读取与搜索后的扩展均产生新的精确引用范围。
- 无本地 embedding 模型时不会生成模拟向量，词法检索仍独立可用。

## 需要外部条件的剩余实测

以下项目没有可伪造的本地替代结果，当前保持“未验证”：

1. **原生桌面交互矩阵**：本机已启动真实 Tauri 应用，但当前自动化接口只能控制浏览器，不能连接原生窗口。仍需在可控制 Windows 桌面的环境中点击验证发送、图片/附件补充、停止、拒绝审批、权限撤销、重启继续、未知结果核对、重新生成、会话切换和大输出。
2. **Qwen 24×3 效果评测**：指定 Qwen 端点可用且原生工具往返通过，但仓库没有冻结的 24 题任务、期望产物和可复现权限沙箱。建立正式题集后才能给出任务完成率，不能用单次协议成功替代。
3. **60 道检索质量集**：仓库没有带正确原文范围的四格式资料和人工标注问题，因此 Recall@8 尚无有效分母。需要冻结语料与标注后运行词法/混合检索。
4. **50,000 分块 Dense 与整机指标**：需要确定 embedding 模型、维度和硬件配置后测量 Dense+RRF P95、峰值内存、冷启动及索引体积。当前仅完成词法查询基准。
5. **远端协议实测与 Unix 进程组**：无对应 Anthropic/Gemini/DeepSeek 等远端凭据及非 Windows 主机；这些路径目前只有契约测试或代码检查。

这些是效果、平台或交互环境验证条件；本轮没有把尚未实现的生产功能归入这一列表。
